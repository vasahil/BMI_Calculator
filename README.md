✨ Key Features

✅ Calculate BMI instantly based on height and weight
✅ Beautiful UI built with Jetpack Compose Material 3
✅ Categorizes BMI into health ranges (Underweight, Normal, Overweight, Obese)
✅ Stores user health data in Firestore
✅ Tracks and updates weight history only when weight changes
✅ Displays progress with a BMI vs Weight history chart 📈
✅ Edit profile details like name, weight, height, and age
✅ Firebase Authentication for secure login/logout
✅ Offline-first reactive UI with StateFlow & Live updates
✅ Clean and maintainable architecture using MVVM + Repository Pattern
